# Resume Formatter

Resume parsing and export helpers.

This package converts structured resume content into downloadable formats used by resume-improvement workflows.

## Contents

- `structure_parser.py` parses and normalizes resume sections.
- `pdf_builder.py` builds PDF resume output.
- `docx_builder.py` builds DOCX resume output.

Keep format-specific rendering details here so agents and routers can work with structured resume content instead of document-generation internals.
